Sistema de Gerenciamento com Google Sheets

Para editar os dados, é necessário fazer login com sua conta Google

⚙️ Configuração Necessária

IMPORTANTE: Para que a edição funcione, você precisa configurar a API do Google Sheets.
Passos:
1. Acesse Google Cloud Console
2. Crie um novo projeto
3. Ative a "Google Sheets API"
4. Crie credenciais OAuth 2.0 para aplicação web
5. Adicione sua URL autorizada (GitHub Pages URL)
6. Copie o Client ID e cole no código (linha 302)

Faça login para visualizar e editar os dados...
